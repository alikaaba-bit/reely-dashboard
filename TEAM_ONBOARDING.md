## FAQ

**Q: Is my data secure?**  
A: Yes. API keys encrypted, database private, HTTPS only.

**Q: Can I edit data?**  
A: No - dashboard is read-only. Edit in source systems (Mercury, ClickUp, Excel).

**Q: Why is some data missing?**  
A: Either:
- API not connected yet (Mercury/ClickUp)
- Excel not synced recently
- Data doesn't exist yet

**Q: How do I add a widget?**  
A: Ask Ali or check with development team.

**Q: Numbers look wrong?**  
A: Click "Sync Data" to refresh. If still wrong, check source system.

**Q: Can I share externally?**  
A: Dashboard is internal only. Don't share URL publicly.
